# 博客写作细则（定稿）

> 与 [CLAUDE.md](../CLAUDE.md)、[.claude/rules/blog-writing.md](../.claude/rules/blog-writing.md) 配套使用。  
> 选题与排期见 [wiki-migration-backlog.md](./wiki-migration-backlog.md)。

## 全站共通

| 项 | 规则 |
|----|------|
| 人称 | 「我」 |
| 语气 | 偏温；可口语，不粗口 |
| 英文 | 类名/API/框架名保留英文 |
| 标题 | `「系列名」\| 第 N 期 · {具体问题}` |
| 引子 | 前 200 字内给出具体场景；禁止「本文介绍…」 |
| 结语 | 一句话教训（≤50 字） |
| description | 60–160 字完整句 |
| tags | 2～5 个；系列名作 tag 之一 |
| TOC | 正文 ≥2500 字自动目录（remark-toc） |
| 发布 | 本地 `pnpm run build` 通过后 push，`draft: false` |
| 修订旧文 | 文首灰字：`更新于 yyyy-mm-dd，增补：…` |
| AI | 可写与 Cursor/Claude 的分工；工具链文专节「协作方式」 |
| 脱敏 | 见下文对照表 |

## 分系列

| 系列 | 字数 | 结构 | 代码 | 配图 |
|------|------|------|------|------|
| 后端踩坑手记 | 2000～3500 | 固定五段（见下） | 中等，❌/✅ | 默认无图；可 Mermaid |
| 工具链 | 2500+ | 自拟小节 +「协作方式」 | 命令/配置为主 | 可选截图 |
| 桌面端手记 | 3000～6000 | 必哥手记体 | 可多段 | Mermaid + 少量截图 |
| 必哥手记 | 3000～6000 | blog-writing 规则 | 按主题 | Mermaid |
| 亲子手记 | ~2500 故事为主 | 暖色叙事 + 技术附录 | 少量 | **2～4 张图** |

### 后端踩坑固定五段

1. `## 你是否也遇到过这些场景`
2. `## 问题的本质是什么`
3. `## 怎么修` / `## 可行方案`
4. `## 代码怎么写`
5. `## 延伸` / `## 结语`

文首：`> 「后端踩坑手记」| 第 N 期`

## 脱敏用词对照（业务 → 公开）

| 避免 | 改用 |
|------|------|
| funciot、具体单位/监区名 | 某审批系统、某单位 |
| 罪犯、狱政、表单业务编号 | 业务主体、审批单、业务编号 |
| 9100 BFF、内网 IP/域名 | 第三方主数据接口、内网网关 |
| 真实人名、单号 | 用户 A、单号示例 |

## 安全债专文

- 真实结构、**匿名类名/配置键**
- 示例值虚构，零真实密钥

## 各系列期号

工具链、后端踩坑、桌面端手记、必哥手记、亲子手记 **独立计数**。
