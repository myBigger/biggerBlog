## 给女儿的话（很短）

爸爸给你做的这座岛，不用赢谁，也不用赶时间。选一辆车，在地上点一下就去挖土；玩够了，天空会慢慢暖起来，像收工回家。  
你开心就好，爸爸在旁边陪你。

下面这段是写给「以后长大的你」和路过博客的工程师看的：我为什么要做、技术上怎么取舍。

---

## 为什么是「岛」，而不是又一款闯关游戏

我白天写企业后台和审批流，晚上不想再把「星级」「排行榜」带回家。女儿小时候对工程车着迷，我就想要一个 **只存在于浏览器里、点开就能玩两分钟** 的小世界。

产品上有三条硬规矩：

1. **无输赢**——没有 Game Over，没有「你输了」。
2. **护眼**——首次有「用眼须知」；单次时长、每日时长、家长区可管；长按角落进设置。
3. **能收工**——日落动画（太阳变月亮），暗示「今天先到这儿」。

它们比「多一辆炫酷挖掘机」更重要。

## 技术选型：Three.js + Vite，而不是「再堆一个 App」

| 选择 | 原因 |
|------|------|
| Web / PWA | iPad 加主屏幕即可；不用走应用商店审核 |
| Three.js | 点地移动、简单地形挖坑，够用 |
| `localStorage` | 工地状态、护眼统计——无账号、无后端 |
| Vite | 与日常前端栈一致，部署顺手 |

第一版其实是 2D；后来加了 **3D 小岛 Demo**（点地开车、挖机堆沙、日落），旧 2D 用 `?mode=2d` 保留回退。  
公开预览：[dig-island.vercel.app](https://dig-island.vercel.app)（`robots.txt` 为 noindex，主要给家人用）。

本地跑：

```bash
git clone https://github.com/myBigger/xiaoxiao-gongcheng-dao
cd xiaoxiao-gongcheng-dao
npm install
npm run dev
# 同 WiFi 的 iPad：npm run dev -- --host
```

## 我踩过的几个坑（父亲版 + 工程师版）

**坑 1：车辆贴图被裁切。**  
换了一张「更省体积」的 PNG，结果模型外轮廓被切掉。教训：儿童向 UI，资源宁可大一点，也要 **保留透明边距**；改图之后要在真机上看一眼。

**坑 2：音效版权。**  
卡通音效单独记在仓库 `CREDITS.md`，不用网上随便下的「免费音效」糊弄过去——这是对娃也是对自己职业习惯的尊重。

**坑 3：部署别拖垮正经项目。**  
工程岛单独仓库、单独 Vercel 项目名 `dig-island`，和博客、工作项目隔离。push 即预览，妈妈验收用 Preview 链接即可。

## 和 Cursor 一起做完，但故事是我的

3D 交互、PWA manifest、护眼计时，不少是 **Cursor 里一句句试出来的**。我会让 AI 写初版动画循环，自己调「日落要够慢、够温柔」；会让它写 `playwright` 冒烟脚本，我在 iPad 上再点一遍。  
**产品决策（无输赢、要护眼）只能是我定**；工具再强，也不能替爸爸决定「孩子该不该被激励攀比」。

这篇发在博客，也是给自己留个印记：工程师的人生不只有 BPM 和 NULL，还有 **愿意花时间陪的人**。

---

## 你若也想给娃做一个小作品

- 先做 **最小可玩**：一辆车 + 一片地 + 一个动作，别一上来 MMO。
- **家长区** 长按进入，比明面上的设置按钮更不容易误触。
- 部署用独立域名或子项目，和生活、工作邮件分开。

欢迎去岛上坐坐：[https://dig-island.vercel.app](https://dig-island.vercel.app)

**教训**：给孩子做的软件，第一指标不是 DAU，是她愿不愿意再点开一次。
